Front-end Development Is Okay Actually

Front-end development is for creatives who want to show off cool things on a public facing website. It's all declarative; you don't have to run a bunch of different statements to generate a window and display it on the screen, you can just put a bunch of divs and spans containing the content you want a web browser will just display it for you. And with css, you can say something is red, and it'll just be red! It's pretty rad.

Back-end developers code using true programming languages, which is also a pretty cool skill to have. They also use Arch Linux and Vim to code and won't shut up about it, which makes them pretty pretentious. Windows is a perfectly viable OS to code on. I won't take any front-end slander from boot.dev while working on this project >:(
